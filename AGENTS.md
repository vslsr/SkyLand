# Codex project instructions

## Project conventions and skills

- Treat `.cursor/` as the canonical location for this project's conventions and project-specific skills.
- Before making changes, read and follow all applicable rules under `.cursor/rules/`. Rules marked `alwaysApply: true` apply to every task in this repository.
- Discover project-specific skills under `.cursor/skills/`. When a task matches a skill, read its `SKILL.md` completely before acting and follow its referenced instructions and resources.
- Treat `.cursor/demo/` as the read-only home for reference examples, currently including `drift-main/` and `line-art-style-magic-cabin-main/`. These examples are not part of the active project source; adapt relevant ideas into the project's own modular structure and do not modify them unless the user explicitly asks.
- Keep new project rules and project-specific skills under `.cursor/rules/` and `.cursor/skills/` respectively; do not create a parallel project convention or skill hierarchy unless the user explicitly requests it.
- Higher-priority system, developer, and user instructions take precedence if a conflict exists.
