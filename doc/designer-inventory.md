# 背包系统设计

* 玩家单人持有的默认背包由 物品栏、背包 构成

* 背包中物品使用：
    * 背包打开时，在下方显示一个物品栏条（参考minecraft），可以将物品拖拽到此物品栏中配置物品栏持有项目，也可以点击菜单中的装配来设置为物品栏物品。设置后，背包中这个物品变为物品栏的物品，转移过去，物品栏也是一条特殊的背包，配置物品栏 相当于将背包内容持有给了物品栏。
    * 点击使用，是先给与玩家Ability，根据物品的配置（长按或点击）激活，完成后关闭能力。而不是现在的持有
* 物品栏中物品使用：
    * 1-9切换手持物品，此时会出现物品对应模型在手（史莱姆对应口）部位，物品没有碰撞和移动，纯粹根据Actor的嵌套方式进行计算坐标
    * 使用流程：手持物品时，物品会给与玩家Ability，根据物品的配置（长按或点击）激活，完成后关闭能力
    * 长按时，必须使用 圆形倒计时UI 来表现，倒计时结束时Active Ability
    * 手持物品不需要额外在玩家上方的UI显示一下 圆形倒计时

# 物品设计

* 说明物品定义的文档格式如下：
    * @i <物品名称>: <说明>
        * M: <模型说明，手持、掉落时使用一套模型>
        * I: <物品Icon说明>
        * F: <物品使用功能>
        * G: <分类>
        * N: <堆叠上限>
        * R: <是否有耐久，有的话耐久度，0或不写为无>

* 位于容器内的物品，可以拖拽一个弹药类型的物品到此物品上，此时配置的是这个拖拽的弹药。
* 使用一个小的icon绘制框显示配置的弹药。可以通过菜单中的卸下弹药来实现卸下弹药。
