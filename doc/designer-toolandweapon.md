# 工具、武器系统

* 工具和武器统称为工具
* 分类：
    1. 玩家可持有的称为轻型工具
    2. 玩家不可持有的，交给建筑系统管理的，被放置出来才能使用的，但是可以作为一个“物件”从物品栏放置出来并使用的内容，是一个`重型工具`
        * 案例：
            * @i 篝火物品：
                * M: 篝火的模型已经实现，可复用。手持的篝火稍微小一圈
                * I: 使用篝火的SVG绘制
                * F: 使用后开启建造模式，可进入建造模式对篝火进行建造，每建造一个消耗1篝火物品
                * G: 重型工具
                * N: 2
                * R: 0
                * A: @todo
                    * 手持: 柴堆抱在身前不动，**不点火**——火焰是放出去那件建造件的事，手上这摞是货
                    * 使用: 一次性 0.12 秒，柴堆向前推出 0.1 米后淡出，同一帧切进建造模式接上幽灵件。纯表现
* 使用标签Tag对目标进行判定：不同武器、工具对目标效果不一样。比如斧子对有木制结构的物品砍的更快，喷火器对可燃标签的物品会有点燃的效果。

* 生命值系统
    * 先接入一个简单的GAS实体生命值Attribute，在场景中生成一些legged-slime，生命值为100
    * 受到伤害、治疗时，弹出一个向上飞出的对应值的数字
    * 生命值为0时，玩家死亡，变为自由视角控制，并且不能再控制这个死亡的角色
        * 死亡状态（两种史莱姆共用）: 服务端把 `dead` 标志和一个自增的死亡 revision 过网。进入死亡后不再接受输入、不再参与推挤，碰撞体保留；生物尸体停留 8 秒后销毁，玩家的尸体留着（人还连着）。动画本身**纯表现**——过网的只有这两个量，摊开和倒下那段在渲染侧积分
        * bpf-slime的死亡动画: 一次性 0.9 秒，由死亡 revision 触发（不用 bool，两帧之间翻回去会漏）
            * 躯体: 改的是蒙皮的**胡克锚点**——横向铺到 1.4×、整团压向地面到 0.25×，同时蒙皮阻尼按 1.6 倍变稠。那一滩因此是被弹簧拉过去的，有塌下去的过程，也仍然会被咬、被拖、被碰撞影响
            * 气泡: 摊开的这一段里逐渐停掉，塌完就不再冒
        * legged-slime的死亡动画: 一次性 0.6 秒，由同一个死亡 revision 触发
            * 髋部: 从 `hipHeight` 按自由落体曲线掉到 `radius × 0.4`（0.44 的半径落在 0.18 米左右），身体坐在髋点上一起掉下去
            * 膜体: 触地那一下横向鼓出 1.35×、纵向压到 0.55×，再松回一部分之后停住——它是趴下了，不是弹回来
            * 腿: 髋开始下落的同一帧停止迈步，落脚点留在倒下前那一步上，两节骨头被 IK 被动折起

## 工具、武器使用流程

* 玩家的物品栏持有武器时，武器会赋予玩家对应的Ability，但是还不Active它
* 在玩家手持工具或武器时，PC端：鼠标在XZ的投影位置控制玩家的面朝方向，移动端：使用一个摇杆控制玩家的面朝方向（两端都已落地。PC 端的投影平面取的是**角色脚下那一层**而不是 y=0，站在地基或山坡上才对得准；移动端是右手边那根瞄准摇杆，推杆方向经相机基落到世界里，和移动摇杆同一套换算。手柄右摇杆走的是同一条）
* TopDown下弹道参考形状如下，可以根据不同的工具产生不同的弹道：
    * PC端：被控制的玩家面朝鼠标在地面上的投影位置XZ+地形高度Y+玩家的持枪的高度
    * 移动端：右侧有一个控制方向的摇杆，移动此摇杆时会控制一个投影在地面上，作为PC端鼠标的替代，计算方式相同
* 玩家使用工具或武器：
    * 长按蓄力攻击：
        * PC端：按下鼠标，出现一个CD圆形倒计时，松开时根据倒计时的计时朝向目标位置发射和使用
        * 移动端：摇杆分为两层，内层控制方向，移动到外层的时候开始出现CD倒计时蓄力，松开时根据倒计时的计时朝向目标位置发射，内层的摇杆范围要大于外侧（内层半径 32px、满行程 48px，所以内层比外面那一环宽。推进外层发的是**主手使用键**本身，触屏和鼠标左键因此走同一条按下 / 蓄力 / 松手的路径；两层之间有 0.06 行程的回滞，手指停在界线上不会让弓一帧一拉一松）
    * 直接开火： @todo
        * PC端：手持此物品时，会让被控制的玩家面朝鼠标在地面上的投影位置XZ加上Y加上玩家的持枪的高度。按下鼠标后，直接触发Ability进行使用。
        * 移动端：摇杆分为两层，内层控制方向，移动到外层的时候，直接触发Ability进行使用。内层的摇杆范围要大于外侧。
* 落地形态：物品目录里 `use.mode` 的第三种取值就是这条——`charge`。`hold` 的圈满是结算，
  `charge` 的圈满只是「攒到头了」，松手才打出去；判定用的蓄力比例与画圈用的是同一个公式，
  所以圈画到哪就是这一箭有多重。
* CD效果：
    * 重型工具CD：使用一个UI游戏内绘制CD圆盘进度，位于此建筑的下方，不受遮挡剔除 @todo
    * 轻型工具CD：使用物品栏中的CD圆盘进度就可以（和长按那圈是同一个环，只是反着走：长按攒满，冷却退空。冷却记在**物品种类**上，和服务端按物品分组的冷却同一个粒度，所以冷却途中把弓拖到另一格也不会立刻又能射；圈不随界面盖上来清掉——那边并不因此停止冷却）

* AI 用武器：会用弓的单位在原型上写一条 `weaponUser`（`itemType` + 交战距离 + 放箭前那段犹豫 + 转身速度），
  武器数值仍然只在物品目录那条 `@w` 上——AI 拿的和玩家拿的是同一把弓，改平衡只改一处。开火走的是
  和玩家完全同一个 `fireWeaponFrom`，所以判定、伤害、标签倍率、复制都只有一条路径。
  两条它自己的规矩：**交战时站定**（正在瞄准的不巡逻，否则两个系统一个把脸转向目标、一个转回路线，
  弓手永远瞄不准）；**蓄到几成由距离反解**（弓手瞄的是人，不是最大射程——总拉满会让八米外的目标
  被一发飞二十二米的箭从头顶掠过去）。目标现在只找玩家：AI 打 AI 要的是阵营，而阵营还不存在。
  AI 手上还没有一把画出来的弓（手持表现体仍是玩家专有的），所以它只有箭，没有弓的形变 @todo

# 轻型武器设计

* @i 木弓：
    * M：实现一个弓的形状
    * I: 使用木弓的SVG绘制
    * F: 使用武器的行为，手持时鼠标、轮盘控制玩家的方向，使用`长按蓄力攻击`，蓄力时绘制一条白色的抛物线细线，蓄力越大越远。松手发射，切换物品时取消(包括原地切换)。
    * G: 轻型工具
    * N: 1
    * R: 0
    * A:
        * 蓄力抛物线: 比例，比例由物品栏那圈倒计时的 ratio [0, 1] 给。白色细线从出手点画到落点，
          落点用的是与服务端同一份换算（`shared/items/weaponStrike.mjs`），弧顶随蓄力变平。
          没过空放阈值时不画——那一箭现在松手也射不出去。纯表现
        * 箭矢: 一次性 0.6 秒上下（射程 ÷ 34 米每秒），松手那一刻发射。一支箭沿**刚才那条预览线的同一条弧**
          飞到落点，箭尖跟着切线走（起手仰着、落地扎下去），到点后插在那儿留 0.45 秒再收走。
          弹道在松手那一刻就算完了——判定也是那一刻结算的，所以箭不需要飞行物理，它只是把那条已经
          定下来的弧走完。纯表现。**屋里每个人都看得见**：快照带出去的是这一发的落点与一个自增计数
          （落点是判定用的那一点，所以所有人画的是同一条弧），接收方按计数变化只射一次
        * 手持: 弓箭贴在身侧，不动 @todo
        * 蓄力: 比例，同一个 ratio。上下弓梢各绕弓握中点向后转 0 → 16°，弓弦中点沿面朝反向后移 0 → 0.18 米成 V 形。纯表现
          （曲线在 `src/render/RenderBowDraw.ts`，形变在 `ThreeWoodBowVisual`。手持的弓因此**不进合批**——
          合批把一件东西烘成一段共享几何，两条能各自转的弓臂在里面没有地方放；地上那把不会被拉开，仍走合批）
        * 持弓手臂前伸 0 → 0.12 米 @todo（角色手臂还没有可驱动的节点）
        * 发射: 一次性 0.12 秒，由一个自增的发射 revision 触发（松手那一刻 +1）。弓弦从当前后移量回到 0 后过冲 0.03 米，按阻尼 12 抖两次收住；弓梢在前 1/3 内回正。纯表现
          （归零与抖动是分开的两段：揉成一条衰减曲线的话，归零那一段会把过冲吃掉，弦看上去只是慢慢松回去。
          **别人那把弓也拉得起来**：快照带的是蓄力的起点与总时长，两端跑同一个 `holdRatio`，所以旁观者
          看到的拉弓程度和射手自己看到的是同一个；下发算好的比例则要每帧发一次，掉一帧弓就卡在半路上）
        * 装填: 一次性 0.1 秒，与 CD 等长——冷却走完的那一刻正好搭好。一支箭从背后箭袋位插值到弓弦中点，弓身抬起 4° 再回位。纯表现 @todo
